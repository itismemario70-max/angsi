---
name: Legends SMP repository workflow
description: The project owner's commit requirement and GitHub push reporting.
---

Commit every code change made to the Legends SMP project. Treat creating a local commit and syncing it to GitHub as separate outcomes; never say it synced unless the push succeeds.

**Why:** the project owner explicitly said, “anything u do make a commit.”

**How to apply:** create a commit for each code-change batch. Attempt a push when authentication is available, then report the commit and push result separately.
