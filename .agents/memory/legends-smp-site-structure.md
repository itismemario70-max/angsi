---
name: Legends SMP public-site structure
description: The project owner's requested navigation, staff preview, and theme behavior for the Legends SMP site.
---

Legends SMP's public content should be split into separate pages reachable from the top navigation. The home page should show a small staff preview with a control to reveal more staff. The site should support light and dark themes, with the choice persisting between visits.

**Why:** the project owner specified these requirements for the Legends SMP site.

**How to apply:** keep future public-site changes consistent with the page navigation, expandable staff preview, and persistent theme toggle.
