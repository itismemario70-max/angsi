---
name: Legends SMP public-site structure
description: The project owner's requested navigation, staff preview, and theme behavior for the Legends SMP site.
---

Legends SMP's public content should be split into separate pages reachable from the top navigation. The home page should show a small staff preview with a control to reveal more staff. The site should support light and dark themes, with the choice persisting between visits.

Keep the homepage's content layout intact while making every public destination reachable from the shared navigation. Staff applications and ban appeals stay on separate pages. Admins manage appeal questions and whether appeals are open; the owner manages application questions, receives applications, and writes the Discord-formatted plugin guide. Staff portraits are uploaded image files, not external image URLs.

**Why:** the project owner specified these requirements for the Legends SMP site.

**How to apply:** keep future public-site changes consistent with the separate pages, full navigation, expandable staff preview, persistent theme toggle, and distinct admin/owner responsibilities.
